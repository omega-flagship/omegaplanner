# Retired: Boards candidate

The owner ruled out Goals and Boards as product surfaces; OmegaHive targets motivations and tasks instead. This
folder keeps the earlier Boards candidate for reference only. It was never installed, nothing imports it, and its
tests are not part of the suite.

| File | What it was |
|---|---|
| `hive_boards.py` | Board-API adapter for candidate `/api/boards/*` routes |
| `ui/` | `TaskBoards.tsx` board UI candidate, its client and a synthetic preview |
| `test_hive_boards.py` | Tests that needed the candidate routes (`OMEGAPLANNER_BOARD_CANDIDATE=1`) |
